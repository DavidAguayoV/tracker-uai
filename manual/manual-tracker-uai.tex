\section{¿Qué es Tracker UAI?}
%%=============================================================================

Tracker UAI es una aplicación para analizar los videos que los estudiantes graban
en el laboratorio y para construir gráficos de datos experimentales. Permite medir
la posición de un objeto cuadro a cuadro, obtener su velocidad y aceleración,
ajustar modelos físicos y exportar tablas y figuras listas para el informe.

\begin{idea}
  Todo el análisis ocurre en tu computador y en tu navegador. No necesitas cuenta,
  ni internet (salvo la primera instalación), ni instalar Excel, Python o MATLAB
  para usarlo.
\end{idea}

El trabajo se organiza en seis etapas secuenciales para el análisis de video, más
una pestaña independiente de gráficos:

\section{Requisitos e instalación}
%%=============================================================================

En \textbf{Windows no necesitas instalar nada}, y en ningún momento se piden
permisos de administrador. En macOS y Linux hace falta \textbf{Python 3.9 o
superior}. El resto de las librerías las instala la aplicación automáticamente
la primera vez que la abres.

\subsection{Windows: desbloquear el ZIP antes de descomprimir}
\label{sec:desbloquear}

Windows marca (\emph{Mark-of-the-Web}) todo archivo descargado de internet, y
esa marca se copia a cada archivo que extraes del ZIP. Es la causa de la
pantalla azul \emph{«Windows protegió tu PC»}. Se quita una sola vez, y hay que
hacerlo \textbf{antes} de descomprimir.

\begin{receta}[Desbloquear el paquete]
  \begin{enumerate}
    \item Clic \textbf{derecho} sobre el archivo ZIP descargado
      $\rightarrow$ \textbf{Propiedades}.
    \item Abajo del todo, si aparece la casilla \textbf{Desbloquear}, márcala.
    \item \textbf{Aceptar}.
    \item Recién ahora: clic derecho $\rightarrow$ \textbf{Extraer todo}.
  \end{enumerate}
\end{receta}

\begin{obs}
  Si ya lo descomprimiste sin desbloquear, borra la carpeta extraída,
  desbloquea el ZIP y extrae de nuevo. Y si aun así aparece la pantalla azul,
  pulsa \textbf{«Más información»} $\rightarrow$ \textbf{«Ejecutar de todas
  formas»}: el aviso es de procedencia, no de contenido.
\end{obs}

\subsection{Windows: Python se resuelve solo}

Al abrir \texttt{Iniciar\_Tracker\_UAI.bat}, el lanzador busca un Python
adecuado en tu equipo. Si no encuentra ninguno, te ofrece descargar su
\textbf{propia copia portable} (unos 11 MB, la distribución
\emph{embeddable} oficial de \texttt{python.org}). Responde que sí. Esa copia:

\begin{itemize}
  \item \textbf{no} requiere permisos de administrador;
  \item \textbf{no} modifica el \texttt{PATH} ni afecta a otros programas;
  \item vive en \texttt{\%LOCALAPPDATA\%\textbackslash TrackerUAI} y se
    desinstala borrando esa carpeta.
\end{itemize}

\begin{obs}
  Si prefieres instalar Python de todos modos, en el instalador de
  \texttt{python.org} elige \textbf{«Install for me only»} («Solo para mí»):
  así tampoco te pedirá administrador. Marcar «Add python.exe to PATH» ayuda,
  pero con este lanzador ya \textbf{no} es obligatorio.
\end{obs}

\subsection{macOS y Linux: instalar Python (una sola vez)}

\begin{receta}[Según tu sistema operativo]
  \begin{itemize}
    \item \textbf{macOS:} instala desde \texttt{python.org/downloads} o, con
      Homebrew, ejecuta \texttt{brew install python}.
    \item \textbf{Linux (Ubuntu/Debian):} instala los paquetes base de Python.
  \end{itemize}
\end{receta}

\begin{lstlisting}[caption={Linux: instalación de Python (terminal).}]
sudo apt update
sudo apt install python3 python3-venv python3-pip
\end{lstlisting}

Para comprobar la instalación, abre una terminal y ejecuta
\texttt{python3 -{}-version}; debe mostrar \texttt{Python 3.9} o superior.

\section{Iniciar el programa}
%%=============================================================================

\begin{receta}[Abrir Tracker UAI]
  \begin{itemize}
    \item \textbf{Windows:} doble clic en \texttt{Iniciar\_Tracker\_UAI.bat}.
    \item \textbf{macOS / Linux:} abre una terminal en la carpeta del programa y
      ejecuta el lanzador (ver abajo).
    \item \textbf{Cualquier sistema (manual):} instala las dependencias y arranca
      con \texttt{streamlit} (ver abajo).
  \end{itemize}
\end{receta}

\begin{lstlisting}[caption={macOS / Linux: lanzador.}]
bash iniciar_tracker.sh
\end{lstlisting}

\begin{lstlisting}[caption={Método manual, cualquier sistema.}]
pip install -r requirements.txt
python -m streamlit run app.py
\end{lstlisting}

La aplicación se abre sola en tu navegador (normalmente en
\texttt{http://localhost:8501}).

\begin{obs}
  La \textbf{primera vez} tarda algunos minutos porque descarga e instala las
  librerías; la ventana de la terminal queda abierta mostrando el avance. Las
  siguientes veces abre en segundos. Para cerrar el programa, cierra esa ventana
  (o presiona \texttt{Ctrl+C} en ella).
\end{obs}

\subsection{Si algo falla en Windows: las dos opciones de rescate}

El lanzador acepta dos argumentos. Para usarlos, mantén \textbf{SHIFT} y haz
clic derecho en un espacio vacío de la carpeta del programa, elige
\emph{«Abrir la ventana de PowerShell aquí»} y escribe la línea que
corresponda.

\begin{lstlisting}[caption={Forzar la copia portable de Python.}]
.\Iniciar_Tracker_UAI.bat --portable
\end{lstlisting}

\begin{lstlisting}[caption={Borrar el entorno y rehacerlo desde cero.}]
.\Iniciar_Tracker_UAI.bat --reparar
\end{lstlisting}

\begin{obs}
  \texttt{-{}-portable} sirve cuando el Python del sistema está roto o
  incompleto: instala una copia independiente y la usa. \texttt{-{}-reparar}
  sirve cuando una instalación anterior quedó a medias; borra solo el entorno
  de trabajo, nunca tus videos ni tus datos.
\end{obs}

\section{Análisis de video, etapa por etapa}
%%=============================================================================

La barra lateral izquierda contiene el selector de etapas, la carga del video y
un indicador de tu progreso.

\begin{obs}[No hace falta memorizar el orden]
  Cada paso termina con un botón \textbf{«Continuar $\rightarrow$»} que te lleva
  al siguiente. Si prefieres saltar a otro paso, el selector de la barra lateral
  sigue disponible en todo momento: nada queda bloqueado.
\end{obs}

\subsection{Paso 1 — Video: elegir el tramo a analizar}

Sube tu video (mp4, mov, avi, mkv, m4v o webm). Lo que se hace en este paso es
\textbf{recortar el tramo} que contiene el movimiento que te interesa.

\begin{receta}[Fijar el tramo]
  \begin{enumerate}
    \item Con el deslizador y los botones, ubica el cuadro donde \textbf{empieza}
      el movimiento y pulsa \textbf{INICIO}.
    \item Ve al cuadro donde \textbf{termina} y pulsa \textbf{FINAL}.
    \item Abajo aparece qué quedó seleccionado: una barra con el tramo sobre la
      duración total y las \textbf{miniaturas del primer y del último cuadro}.
      Compruébalas antes de seguir.
  \end{enumerate}
\end{receta}

\begin{idea}
  Acotar el tramo hace que todo el análisis sea mucho más rápido: el programa
  trabaja solo sobre lo que te interesa, no sobre el video completo.
\end{idea}

\subsection{Paso 2 — Calibración: cuánto mide un píxel}

El video está en píxeles, pero tu informe necesita metros. El programa te guía
con una lista numerada y te dice en cada momento qué toca marcar.

\begin{receta}[Calibrar]
  \begin{enumerate}
    \item Haz clic en \textbf{un extremo} de la distancia conocida (una regla,
      una huincha, una hoja) y luego en \textbf{el otro}.
    \item Haz clic donde quieras el \textbf{origen} de coordenadas.
    \item Escribe cuánto mide esa distancia \textbf{eligiendo la unidad}
      (\si{\centi\meter}, \si{\milli\meter} o \si{\meter}).
    \item (Opcional) Activa \emph{«Mi eje $x$ no es horizontal»} si trabajas en un
      plano inclinado, y marca la dirección $+x$.
  \end{enumerate}
  No hay que pulsar ningún botón: la calibración \textbf{se aplica sola} en
  cuanto están todos los datos.
\end{receta}

\begin{errcomun}
  Escribir \texttt{30} pensando en una regla de \SI{30}{\centi\meter} pero con la
  unidad en metros. Eso deja todos los resultados escalados por un factor 100.
  Por eso el programa muestra a cuánto equivale un píxel y qué \textbf{ancho real}
  tendría el encuadre: si ese ancho no se parece a lo que ves en el video, la
  distancia o su unidad están mal.
\end{errcomun}

\subsection{Paso 3 — Tracking: seguir el objeto}

El programa arranca en modo \textbf{automático}, que es lo que conviene casi
siempre: señalas el objeto una sola vez y el programa lo busca en el resto del
tramo.

\begin{receta}[Seguimiento automático por plantilla]
  \begin{enumerate}
    \item \textbf{Haz clic justo encima del objeto.} Aparece de inmediato un
      recuadro verde y, debajo, un recorte ampliado de lo que se va a seguir.
    \item Ajusta el \textbf{tamaño del recuadro} con el deslizador: debe encerrar
      el objeto y lo menos posible de fondo.
    \item Pulsa \textbf{Ejecutar seguimiento}. Verás la detección en vivo.
  \end{enumerate}
  Si prefieres, también puedes \textbf{arrastrar} para dibujar el recuadro a mano.
  Los otros métodos son \emph{Color} (clic para tomar el color del objeto) y
  \emph{CSRT}.
\end{receta}

\begin{ojo}
  Al terminar, el programa avisa si quedaron \textbf{cuadros sin detección}: es la
  señal de que el seguimiento perdió el objeto. En los desplegables puedes ver
  todas las detecciones superpuestas y \textbf{corregir} cuadro por cuadro; también
  puedes editar la tabla de datos directamente. Si el automático falla del todo,
  cambia al modo \textbf{manual} y haz clic sobre el objeto en cada cuadro.
\end{ojo}

\subsection{Paso 4 — Cinemática}

Arriba aparece un \textbf{resumen del movimiento}: cuántos puntos se analizaron,
la duración, la distancia recorrida, el desplazamiento neto, la rapidez media y
máxima y la aceleración media. Un bloque de \textbf{calidad de los datos} te avisa
si hay mucho ruido de marcado, cuadros faltantes o pocos puntos para un ajuste
confiable. Abajo están los gráficos de posición, velocidad, aceleración y
trayectoria.

\begin{obs}
  Activa el \textbf{suavizado} si los datos tienen ruido, sobre todo para la
  aceleración. Las figuras que exportes usarán esa misma señal suavizada, de modo
  que la figura de tu informe es exactamente la que viste en pantalla.
\end{obs}

\subsection{Paso 5 — Ajuste de modelos}

Elige un \textbf{preset} según tu laboratorio (gravedad en plano inclinado,
arrastre y velocidad terminal, colisiones, péndulo cónico, péndulo bifilar, MHD)
o el modo \textbf{genérico}. El programa entrega los parámetros con su
\textbf{incertidumbre} y el coeficiente de determinación $R^{2}$.

\begin{obs}[Los laboratorios 2 se cierran fuera de la app]
  Tanto el Lab~2 de FIS101 como el de FIS201 se resuelven con un ajuste lineal
  sobre \emph{varios} videos: $v_t^{2}$ contra $m$ en uno, $T^{2}$ contra $H$ en
  el otro. Ese ajuste se hace en una planilla, como pide tu guía. Lo que
  entrega la app por video es el dato que entra a ese ajuste ($v_t$ o $T$).
\end{obs}

Además, en esos dos presets hay un panel plegable de \textbf{control de orden de
magnitud}: entregando la masa y el diámetro del filtro (FIS101), o la masa, la
separación de los hilos y su largo (FIS201), calcula el $C_d$ de esa caída o el
$I_{zz}$ de ese largo. \textbf{No es el resultado que se informa}: sirve para
darse cuenta en el momento de un error de calibración, de unidades o de lectura,
antes de acumular veinte tomas mal medidas.

\begin{errcomun}
  En el péndulo bifilar, usar el \textbf{largo de la barra} en vez de $d$, la
  \emph{semiseparación entre los hilos}, da un momento de inercia nueve veces
  mayor. Y contar los cruces por el equilibrio en ambos sentidos, en vez de
  siempre en el mismo, entrega medio período y un $I_{zz}$ cuatro veces menor.
\end{errcomun}

\subsection{Paso 6 — Exportar}

Las figuras (posición, velocidad, aceleración, trayectoria y error de detección)
\textbf{se ven en pantalla} y cada una tiene su propio botón de descarga, así que
puedes bajar solo la que necesitas para tu informe. También puedes descargar el
\textbf{CSV} con todos los datos crudos y derivados, o un \textbf{ZIP} con todo
junto.

\section{Pestaña «Gráficos» (datos manuales)}
%%=============================================================================

Esta herramienta es \textbf{independiente del video}: sirve para graficar datos
escritos a mano. Está pensada para Física I; por ejemplo, graficar la aceleración
en función de $\sin(\theta)$ en el péndulo simple.

\begin{receta}[Construir un gráfico en pocos pasos]
  \begin{enumerate}
    \item Escribe el título y los nombres de los ejes.
    \item Ingresa tus valores de $x$ e $y$ en la tabla (agrega filas con el botón
      \texttt{+}).
    \item El gráfico de dispersión aparece automáticamente.
    \item Elige el ajuste (lineal o cuadrático): verás la curva, la \textbf{ecuación}
      y el $R^{2}$.
    \item Crea más series (con nombre y color) para comparar conjuntos de datos.
    \item Descarga el gráfico en \textbf{PNG} o \textbf{SVG} para tu informe.
  \end{enumerate}
\end{receta}

\begin{ejemplo}[Péndulo simple: $a$ frente a $\sin\theta$]
  Al graficar la aceleración medida contra $\sin\theta$ y aplicar un ajuste lineal,
  la pendiente corresponde a la aceleración de gravedad $g$, y el $R^{2}$ indica
  qué tan bien la recta describe los datos.
\end{ejemplo}

\section{Consejos para grabar los videos}
%%=============================================================================

\begin{estrategia}[Buenas prácticas de grabación]
  \begin{itemize}
    \item Cámara \textbf{perpendicular} al plano del movimiento y \textbf{fija}
      (trípode o apoyada); esta versión no corrige perspectiva.
    \item La regla de calibración debe estar \textbf{en el mismo plano} que el
      movimiento.
    \item Buena iluminación; objeto bien visible y, si usarás seguimiento por color,
      de un \textbf{color distinto al fondo}.
    \item Para movimientos rápidos, graba en \textbf{cámara lenta} e indica el fps
      real de captura en \emph{Opciones avanzadas}.
  \end{itemize}
\end{estrategia}

\section{Compartir el programa}
%%=============================================================================

En \textbf{Windows no hay requisitos previos} en el equipo de destino: si no
tiene Python, el lanzador ofrece descargar su propia copia portable, sin
permisos de administrador. En macOS y Linux sí hace falta \textbf{Python 3.9+}.

\begin{receta}[Distribución]
  \begin{itemize}
    \item \textbf{Windows:} ejecuta \texttt{Crear\_paquete\_para\_compartir.bat}
      para generar un ZIP limpio y envíalo. Advierte a quien lo reciba que
      \textbf{desbloquee el ZIP antes de descomprimirlo}
      (sección~\ref{sec:desbloquear}); luego sigue
      \texttt{LEEME\_ESTUDIANTES.txt}.
    \item \textbf{macOS / Linux:} comparte la carpeta (sin la subcarpeta del
      entorno virtual) junto con \texttt{iniciar\_tracker.sh}.
  \end{itemize}
\end{receta}

\begin{resumen}
  \begin{itemize}
    \item Tracker UAI funciona en Windows, macOS y Linux. En Windows no requiere
      instalar nada ni permisos de administrador: el lanzador resuelve Python
      por sí solo.
    \item El análisis de video sigue seis etapas: Video, Calibración, Tracking,
      Cinemática, Ajuste y Exportar.
    \item La pestaña \emph{Gráficos} permite analizar datos experimentales sin video.
    \item Todos los resultados se exportan como CSV e imágenes para el informe.
  \end{itemize}
\end{resumen}
